# Goal Weight Calculator

Goal weight and adjustable calorie-deficit calculator, installable as a PWA. Everything runs on-device; no data is collected.

Live: https://chewiewins.github.io/goal-weight-calculator/

- `index.html` – basic calculator
- `advanced.html` – fibre/macro planner and daily tracker
- `guide.html` – user guide; `privacy.html` – privacy notes
- `poster.pdf` / `poster.png` – printable poster
- `manifest.webmanifest`, `sw.js`, icons – PWA files (bump `VERSION` in `sw.js` on each release)

Each HTML file also works standalone when opened locally (service worker only registers on http/https).
